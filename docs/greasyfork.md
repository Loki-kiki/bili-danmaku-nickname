# B站直播画面弹幕昵称标注

给 B 站直播间**画面上飘过的弹幕**补上发送者昵称，并把值得注意的人一眼挑出来。

> 只改直播画面上的滚动/固定弹幕，不碰右侧聊天区，不改 B站 自己的界面。
> 代码和说明由 AI 协助编写。

**源码：** https://github.com/Loki-kiki/bili-danmaku-nickname
**完整更新日志：** https://github.com/Loki-kiki/bili-danmaku-nickname/blob/main/CHANGELOG.md

## 🆕 2.6.0 新增：高光效果

「值得注意的人」原来只换个颜色，弹幕一多就淹没了。现在可以给他们的弹幕套上效果：

| 效果 | 样子 |
|---|---|
| **底牌** | 弹幕背后垫一块深色底，带档位色描边和左侧色条。不会动，弹幕飘到一半时扫一眼也认得出 |
| **绕圈光段** | 两段光沿着框转圈（同屏最多 6 条，再多自动降级，不拖慢页面） |
| **入场涟漪** | 弹幕出现那一刻向外扩两圈，然后就收起 |

默认分档：越显眼的效果给越少的人。

| 档位 | 默认效果 |
|---|---|
| ◆ 自定义名单 / 指定人 | 底牌 + 绕圈 + 涟漪 |
| ❤ 已关注 | 底牌 + 涟漪 |
| ⭐ 粉丝数达标 | 底牌 |
| 关键词 | 只换色 |

每档都能在设置面板「高光效果」里多选；全不选就只换色。

## ✨ 功能

### 标注

| 能力 | 说明 |
|---|---|
| 昵称前缀 | 每条弹幕前显示「昵称:」，颜色和正文分开 |
| ⭐ 粉丝数 | 粉丝 ≥ 阈值（默认 50000）的人 |
| ❤ 已关注 | 当前登录账号已关注的人 |
| ◆ 自定义名单 | 自己列的昵称或 UID，按 UID 记，改名也认得出 |
| 粉丝牌 / B站等级 / 舰长 / 房管 | 默认关（前缀太长会把弹幕撑宽），需要时再开 |
| 关键词高亮 | 命中关键词的弹幕换色，每个关键词可单独配色 |
| 指定人 | 发弹幕时高亮，进直播间时提示 |
| 表情弹幕 | 纯表情和图文混排也标昵称，不撑大表情图 |
| 固定弹幕 | 顶部/底部固定弹幕、高能弹幕同样标注 |

### 悬停身份卡

鼠标停在一条弹幕上，**只钉住这一条**，弹出身份卡：头像、昵称、UID、粉丝数、等级、签名、空间链接。新飘过来的弹幕不会抢走它，鼠标可以移到卡片上点「进入空间」。

### 高亮记录

命中标注的弹幕自动收录：搜索（关键词 / 完全匹配 / 正则）、按标签筛选、导出到剪贴板、单条或批量删除、点名字跳空间。

### 设置面板

左下角悬浮球打开。深浅双主题，可拖动、可调大小，位置和大小都会记住。改了立即生效。

## 📥 安装

1. 装 [Tampermonkey](https://www.tampermonkey.net/)（Edge / Chrome / Firefox）
2. 点本页的「安装此脚本」
3. 打开任意 B站直播间，左下角出现悬浮球就是装好了

**从 1.0.x 升级**：直接覆盖安装，原来的设置、自定义名单、记录都会保留。

## ⚙️ 容易误解的设置

| 项 | 默认 | 说明 |
|---|---|---|
| 粉丝数阈值 | 50000 | 调低会让更多普通人带 ⭐，画面会花 |
| 粉丝牌 / 等级 / 舰长 / 房管 | 关 | 长前缀会把弹幕撑宽 |
| API 查询范围 | 都查 | 改「只查值得的人」可在大直播间少发请求 |
| 高光效果 | 见上表 | 关键词默认不加框：命中太多会满屏 |

## ❓ 常见问题

**有的弹幕没标昵称？**
确认面板里「启用」「显示昵称」开着。仍有问题：油猴菜单 →「诊断导出」，把剪贴板内容贴到反馈区。

**❤ 关注标记不亮？**
需要登录 B站，脚本读取的是当前账号的关注关系。

**大直播间 ⭐ / ❤ 出得慢？**
粉丝数和关注关系要请求接口查，人多时排队。粉丝牌、等级、舰长、房管直接从弹幕里读，不受影响。

**画面花了 / 太多框？**
设置面板「高光效果」里把低档位的效果取消掉，或者调高粉丝数阈值。

## 🔒 隐私

只请求 B站 自己的接口（用户信息、关注关系、弹幕连接）。设置和记录都存在你本机的 Tampermonkey 里，不上传到任何地方。
